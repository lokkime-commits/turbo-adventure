Напиши программу "Генератор вдохновения":
Импортируй модуль random
Создай список из 5 мотивирующих фраз
Выводи случайную фразу при каждом запуске

import random
phrases = [
"Ты сможешь! Программирование — это просто!",
"Ошибки — это путь к успеху!",
"Каждая строка кода делает тебя лучше!",
"Python любит тебя!",
"Сегодня твой день для великих идей!"
]

random_phrase = random.choice(phrases)
print(random_phrase)
